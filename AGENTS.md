# Agent and Contributor Guidance

## English

Human contributors and coding agents working on this project must:

- Read [`verificacions-phase2.md`](./verificacions-phase2.md) before making changes. It is the approved, normative engineering standard for this repository.
- Review applicable instructions and skills under `./.agents/rules` and `./.agents/skills` when those directories exist.
- Review `./memory-bank` when it exists.
- Before analyzing, modifying, or generating project content, check the latest applicable guidance and preserve existing project conventions and user changes.
- Run focused checks for the work performed and report which checks were actually executed and their results. Do not describe an unrun check as passing.

## Espanol

Los colaboradores humanos y agentes de codigo que trabajen en este proyecto deben:

- Leer [`verificacions-phase2.md`](./verificacions-phase2.md) antes de realizar cambios. Es el estandar de ingenieria aprobado y normativo de este repositorio.
- Revisar las instrucciones y skills aplicables en `./.agents/rules` y `./.agents/skills` cuando existan esos directorios.
- Revisar `./memory-bank` cuando exista.
- Antes de analizar, modificar o generar contenido del proyecto, consultar la guia aplicable mas reciente y preservar las convenciones existentes y los cambios del usuario.
- Ejecutar comprobaciones focalizadas para el trabajo realizado e informar cuales se ejecutaron y sus resultados. No describir como exitosa una comprobacion que no se ejecuto.
